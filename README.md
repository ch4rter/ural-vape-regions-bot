# Telegram-бот «Регион — менеджер»

Бот ищет введённое название в Excel-файле и показывает закреплённого менеджера. Он не определяет географию самостоятельно: каждое нужное название должно присутствовать в таблице.

Также бот содержит раздел `🗃 База данных` с товарами, разделами и рабочими материалами. Управлять им может только Telegram-пользователь, чей ID указан в `ADMIN_IDS`.

Раздел `💰 Цены и ассортимент` ищет товарные группы в едином общем прайсе и рассчитывает цены со скидками 5%, 10% и 15%. Запрос с характеристиками товара (например, `Vaporesso XROS 0.6 2мл`) открывает конкретные позиции с отдельными ценами. Артикулы в пользовательском поиске не используются.

Раздел `🔔 Ожидания` хранит клиентские запросы менеджера. Для добавления можно написать непосредственно в клиентском чате `/wait название товара` либо нажать `➕ Добавить ожидание` в личном меню, если общего чата нет. В первом случае бот определит чат, очистит из его отображаемого названия служебную приписку `URAL VAPE` и автоматически пришлёт менеджеру личную карточку для дооформления. В карточке можно изменить товар, добавить или удалить комментарий, перейти в клиентский чат и закрыть ожидание одним нажатием. Широкий запрос (`жидкости OGGO`, `картриджи XROS`) отслеживает всю подходящую группу; запрос с числовыми характеристиками ищет конкретный вариант. Категория проверяется строго, поэтому картриджи не смешиваются с устройствами, а жидкости — с ароматизаторами. Сразу после применения общего прайса бот проверяет появившиеся позиции и отправляет менеджерам уведомления. Одна и та же позиция повторно не уведомляется. Артикулы в сопоставлении не используются.

Из результатов поиска можно добавить одну или сразу все найденные группы в подборку и сформировать отдельный клиентский Excel-прайс. Бот делает отфильтрованную копию общего прайса: сохраняет его оформление, формулы, объединённые ячейки и изображения, удаляя лишние товарные строки. Доступны базовые цены и вариант со скидкой 10%. Подборка рассчитана максимум на 50 товарных групп.

Новый внешний пользователь в личном чате сначала заполняет одноразовую анкету: имя, должность, регион, компанию и формат работы. Бот определяет ответственного по действующей таблице территорий, отправляет менеджеру анкету с кнопкой связи и показывает клиенту контакт менеджера. После этого пользователю становятся доступны поиск менеджера по территории и опубликованные администратором разделы базы. Анкеты хранятся в `materials.sqlite3`; главный и младший администраторы могут выгрузить их в Excel через раздел управления.

Команда `/прайс` доступна всем участникам групп, в которые добавлен бот. Внутренние цены, отчёты, ожидания и управление остаются закрытыми. Администратор добавляет сотрудников по Telegram ID или `@username` через `⚙️ Управление базой → 👥 Белый список`. При первом входе разрешённый username привязывается к постоянному Telegram ID. Для автоматической доставки анкет менеджер должен быть добавлен в белый список по своему username и хотя бы один раз запустить бота; иначе новая анкета направляется главному администратору.

В личном диалоге постоянно доступна нижняя кнопка `🏠 Главное меню`. Она отменяет текущий незавершённый сценарий и возвращает пользователя на главный экран, но не позволяет пропустить обязательную анкету. При добавлении бота в новую клиентскую группу он публикует понятное приветствие с описанием команд `/прайс` и `/materials`; служебная настройка характеристик отправляется сотруднику отдельно.

## Быстрый запуск в Windows

1. Установите Python 3.10 или новее.
2. Создайте бота через Telegram-аккаунт `@BotFather` и скопируйте токен.
3. Откройте PowerShell в папке проекта и выполните:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python create_template.py
Copy-Item .env.example .env
```

4. Откройте `.env` и замените значение `BOT_TOKEN` на токен от BotFather.
5. Запустите:

```powershell
.venv\Scripts\python bot.py
```

Остановить бота можно сочетанием `Ctrl+C`.

## Excel-файл

По умолчанию бот читает `managers.xlsx`, первый лист и первые две колонки:

| Название | Менеджер |
|---|---|
| Тамбов | Андрей |
| Тамбовская область | Андрей |
| Минск | Елена |

- Заголовок допустим, но не обязателен.
- Пустые строки пропускаются.
- Поиск не зависит от регистра, повторных пробелов и различия `е/ё`.
- Одно название можно записать несколько раз. Бот покажет всех соответствующих менеджеров.
- После изменения Excel перезапустите бота, чтобы загрузить новые данные.
- Не держите Excel открытым во время замены файла на сервере.

Путь к другой таблице можно задать параметром `EXCEL_PATH` в `.env`.

## База данных товаров

В главном меню доступны два независимых режима:

- `🔎 Найти менеджера` — после включения бот принимает текстовые запросы по территориям;
- `🗃 База данных` — каталог товаров и подготовленных материалов.

Администратору дополнительно доступна кнопка `⚙️ Управление базой`. Через неё можно создавать, переименовывать, скрывать и удалять товары, создавать разделы и добавлять в них текст, изображения и документы. Каждый раздел отдельно переключается между режимами `🔒 Только сотрудникам` и `🌐 Доступно всем`. Публичность распространяется на всё содержимое раздела; существующие и новые разделы закрыты по умолчанию. В группах публичный каталог открывается командой `/materials` или `/материалы`.

Сами файлы повторно не сохраняются на сервере: база хранит выданные Telegram идентификаторы файлов. Структура каталога и тексты находятся в `data/materials.sqlite3`. Этот файл не загружается в Git и должен резервироваться отдельно.

Настройки в `.env`:

```env
MATERIALS_DB=data/materials.sqlite3
MANAGED_EXCEL_PATH=data/managers.xlsx
PRICES_DB=data/prices.sqlite3
PRICE_STORAGE=data/prices
ADMIN_IDS=5533726476
```

Несколько администраторов можно указать через запятую.

Администратор может скачать ZIP-резервную копию прямо в Telegram. В архив входят база товаров `materials.sqlite3`, действующая таблица `managers.xlsx` и краткое описание.

## Рассылки по клиентским чатам

Бот автоматически сохраняет название и Chat ID групп, в которые его добавляют, отмечает чат неактивным при удалении и запоминает пользователя, выполнившего добавление. Сотруднику из белого списка бот предлагает отметить характеристики клиента: `СП`, `БП`, `Железо`, `Конструкторы`. Изменить их в любое время можно командой `/chat` в клиентской группе.

В разделе `📣 Рассылки клиентам` администратор рассылок может выбрать несколько характеристик и выгрузить подходящие активные чаты. Отбор работает по принципу ИЛИ: для выбора `БП` и `Железо` достаточно наличия любой из этих характеристик. В Excel можно удалить строки или поставить `Нет` в колонке `Включить`, затем загрузить проверенный файл в стандартный сценарий рассылки. Отдельно доступны полный реестр и список чатов без характеристик.

Рассылка поддерживает один готовый Telegram-пост: текст, фото, видео, анимацию или документ с подписью. Бот показывает предпросмотр, обязательно копирует пост в выбранную служебную группу и только после подтверждения начинает массовую отправку. Дубли Chat ID удаляются, ход отправки показывается в Telegram, а после завершения формируется Excel с результатом по каждому чату.

В белом списке доступны роли `Пользователь` и `Младший администратор`. Младший администратор получает доступ к рассылкам, но не к управлению товарами, прайсами, резервными копиями и ролями. Назначать роли может только главный администратор из `ADMIN_IDS`. Тестовый пост всегда отправляется в служебный чат `-5565597780`.

Telegram не предоставляет боту готовый список групп, куда он был добавлен до установки функции. Старые зарегистрированные чаты сохраняются, а характеристики для них можно проставить командой `/chat`. В клиентских группах бот отвечает только на разрешённые команды и кнопки.

Новый Excel также можно загрузить через административную панель. Бот проверяет обязательные колонки, показывает число корректных строк и применяет файл только после подтверждения. Загруженная таблица сохраняется в `data/managers.xlsx`, поэтому обновления кода через Git её не перезаписывают. Предыдущие версии автоматически сохраняются в `data/backups/`.

## Цены и ассортимент

Администратор загружает один общий `.xlsx` через `⚙️ Управление базой → 💰 Прайсы`. Перед применением бот показывает дату, число групп, число товарных позиций и количество акционных строк.

В этом же разделе доступна отдельная кнопка `🔄 Сформировать из МоегоСклада`. Она выполняет только `GET`-запросы к JSON API, получает штатное значение `Доступно` по складам `Мордор`, `Годзибасы` и `Жможики`, исключает недоступные позиции и формирует тестовый общий прайс за текущую дату. Бот присылает Excel администратору, но не заменяет действующий прайс, не меняет базу цен, не создаёт отчёт изменений и не запускает уведомления листа ожидания.

Для интеграции рекомендуется создать в МоемСкладе отдельного сотрудника только с правами просмотра ассортимента, цен, складов и остатков. Настройки:

```env
MOYSKLAD_TOKEN=токен_доступа
MOYSKLAD_STORES=Мордор,Годзибасы,Жможики
MOYSKLAD_CASH_PRICE_TYPE=от 50т.р. нал
MOYSKLAD_CASHLESS_PRICE_TYPE=от 50т.р. безнал
```

По умолчанию бот в первую очередь выбирает точные типы `от 50т.р. нал` и `от 50т.р. безнал`, поэтому цены `Дистр` в тестовый прайс не попадут. Последние две переменные позволяют переопределить этот выбор, если названия в МоемСкладе изменятся.

При повторной загрузке бот сравнивает новый общий прайс с предыдущим и формирует отчёт: появившиеся и закончившиеся позиции, изменения цен, новые и исчезнувшие товарные группы. Хранится последнее сравнение. Краткая сводка и подробный Excel доступны всем разрешённым пользователям в разделе `📊 Изменения`.

После формирования отчёта администратор может вручную нажать `📣 Отправить общий отчёт`. Бот показывает предпросмотр и количество получателей, а отправка начинается только после отдельного подтверждения. Один и тот же отчёт нельзя разослать повторно. Уведомление получают пользователи белого списка с привязанным Telegram ID.

Товарные группы определяются по строкам прайса без цен. Для показа берётся последняя часть пути после `/`, а полный путь участвует в умном поиске. Следующие строки с ценами считаются вариантами группы до следующего раздела. У акционных позиций убирается только служебная приписка `АКЦИЯ`; сами товары, цены и наличие сохраняются. Акционные строки из общего раздела распродажи автоматически объединяются в группы по названию модели.

Исходные прайсы сохраняются в `data/prices/`, предыдущие версии и копии базы — в `data/prices/backups/`. Эти рабочие данные исключены из Git.

В пользовательской вкладке `📄 Прайсы` можно скачать исходный общий файл либо автоматически сформированную копию со скидкой 10%. В копии пересчитываются обе базовые колонки нал/безнал, заголовки получают отметку о скидке, а исходный файл остаётся неизменным.

## Перенос на сервер

Скопируйте папку проекта и `managers.xlsx` на сервер, установите зависимости, создайте `.env` с токеном и запустите `python bot.py`. Для постоянной работы процесс позднее можно оформить как службу `systemd` или запустить в Docker.

## CRM-бета и Google Таблица

Раздел `📇 CRM · Бета` видят только Telegram ID из `CRM_BETA_IDS`. Актуальные карточки клиентов читаются из листа `Активные клиенты`; структура и колонки листа не меняются. Бот умеет искать клиента, дописывать результат общения в `Примечание`, обновлять даты и статус, отмечать заказ и менять цвет товарных групп. Красная отметка требует обязательную причину, зелёная означает, что клиент покупает товарную группу, отсутствие заливки — что информация не заполнена.

Задачи, список обзвона и журнал действий дня хранятся отдельно в `data/crm.sqlite3` и включаются в резервную копию бота. JSON-ключ Google никогда не включается в архив или Git.

Настройки подключения:

```env
CRM_BETA_IDS=5533726476
CRM_DB=data/crm.sqlite3
GOOGLE_CREDENTIALS=secrets/google-service-account.json
GOOGLE_SPREADSHEET_ID=1G3OVKOVvueHapaQVMcAdijZRuoGRZ4gV1G2shnmpdkQ
GOOGLE_SHEET_NAME=Активные клиенты
```
